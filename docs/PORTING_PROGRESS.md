# Прогресс переноса

Цель — восстановление работоспособного опубликованного содержимого PowerCraft 2 с сохранением принятой основы Horizon. Экспериментальные/неисправные/незавершённые функции сейчас отложены. Полный мод **не завершён**. Источник и три категории оригинала: [ORIGINAL_REGISTRY.md](ORIGINAL_REGISTRY.md), подробные классы/рецепты/UI: [ORIGINAL_MECHANICS.json](ORIGINAL_MECHANICS.json). Проверенная база — [BASELINE.md](BASELINE.md).

Используются статусы: **Не начата**, **В разработке**, **Реализована, не протестирована**, **Успешно протестирована в игре**, **Заблокирована возможностями Horizon**. «Не протестирована» означает отсутствие игровой приёмки, даже если Rust/интеграционные проверки прошли. По последнему указанию пользователя исходная категория 2 исключена из текущей очереди: статус «Отложена: незавершена в оригинале». Не исправлять её попутно с рабочими механизмами.

Для текущих лент стабильный публичный setter клиентской скорости отсутствует; проверенный pin-specific адаптер 0.1.1 сохранён без расширения записи на позиции/стеки.

## Следующая последовательность

1. Игровая приёмка 0.4.0: Speedy-разгрузка, новый detector, регрессия трёх лент и сохранение. 26 файлов базы побайтно прежние, языки/вкладка дополнены без удаления записей.
2. Следующая — перенаправляющая лента по опубликованному поведению; затем рабочие фильтры/выбрасывание/подъёмники Transport с отдельной проверкой сохранения/GUI.
3. Совместимые источники/приёмники инвентарей, включая вагонетки, только после проверки необходимых гарантий API.
4. Подтверждённые рабочие Core/Deco и остальные исходные механизмы по зависимостям; экспериментальные Logic/Storage/Mobile и неисправные подфункции отложены.
5. Не добавлять новых игровых идей. Принятые отличия 0.2.0 (геометрия, плавная скорость, pickup/despawn, прежние рецепты) сохранять.

## Сравнение с опубликованным оригиналом и наши отличия

Все 62 декларации и конкретные компоненты распределены по пяти категориям в [PORTING_COMPARISON.json](PORTING_COMPARISON.json): уже перенесён и работает; перенесён частично; отсутствует; наш дополнительный функционал; экспериментален/незавершён в оригинале. Полный Normal/Speedy/Brake остаётся перенесён частично: базовое движение подтверждено, но все дополнительные Forge-действия ещё не восстановлены.

Speedy и Brake есть в опубликованном оригинале — они не считаются нашими новыми видами блоков. Собственные принятые адаптации: высота 1/4 вместо 1/16, ограниченная скорость и клиентское предсказание, обычный pickup/despawn Horizon, сохранённые medium-рецепты. Beta-рецепты отличаются; прежние определения не удаляются и не заменяются. См. [PUBLISHED_RELEASE.md](PUBLISHED_RELEASE.md).

Speedy с 0.3.1 разгружается по прямому запросу пользователя. Это согласованное дополнение, хотя опубликованный класс не вызывает storeNearby. Тесты и официальный check прошли, игровая приёмка нового поведения ещё требуется.
