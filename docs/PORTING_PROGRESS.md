# Прогресс переноса

Цель — все существующие механики PowerCraft 2, поэтапно. Полный мод **не завершён**. Источник и три категории оригинала: [ORIGINAL_REGISTRY.md](ORIGINAL_REGISTRY.md), подробные классы/рецепты/UI: [ORIGINAL_MECHANICS.json](ORIGINAL_MECHANICS.json). Проверенная база — [BASELINE.md](BASELINE.md).

Используются статусы: **Не начата**, **В разработке**, **Реализована, не протестирована**, **Успешно протестирована в игре**, **Заблокирована возможностями Horizon**. «Не протестирована» означает отсутствие игровой приёмки, даже если Rust/интеграционные проверки прошли. Категория оригинала 2 означает необходимость исправлений при переносе, а не исключение из объёма.

## Transport — текущий приоритет

| Механика | Статус | Реальный объём / что осталось |
| --- | --- | --- |
| Базовая лента: блок, размещение, facing, плавное движение предметов | Успешно протестирована в игре | Подтверждено пользователем для native 0.1.1 + content 0.1.0. Регрессионные тесты 0.2.0 сохраняют расчёт и исходные данные; новый выпуск в игре не проверен |
| Быстрая лента `powercraft2:speedy_conveyor` | Реализована, не протестирована | Блок/предмет, четыре направления, модели/текстуры, рецепты, скорость ×2, server/client tick |
| Тормозная лента `powercraft2:brake_conveyor` | Реализована, не протестирована | Скорость ×0,6; redstone гасит горизонтальную скорость; собственный powered синхронизируется клиенту при контакте с предметом |
| Бумажные medium-рецепты обычной/быстрой ленты | Реализована, не протестирована | Альтернатива с выходом 1; кожаные рецепты дают 4 |
| Контакт/направления/чистое ядро и общий client/server расчёт | Реализована, не протестирована | 25 Rust-тестов; игровые массовая нагрузка, края и LAN ещё не приняты |
| Подключение инвентарей к концам и бокам | Не начата | Нужны sided slots, полное сравнение компонентов, атомарное изъятие/вставка без дюпов |
| Упаковка стеков поверх стандартного слияния Horizon | Не начата | Не повторять сравнение, теряющее NBT/компоненты; стандартное слияние движка сохранено |
| Особые действия ведра/бутылки и размещение вагонетки | Не начата | Нужны предметные транзакции и серверное использование |
| Despawn-политика оригинальных лент | Не начата | Текущий прототип сохраняет обычное время жизни Horizon |
| Движение игроков/мобов/XP/вагонеток | Не начата | Сейчас воздействуем только на item entities; движение остальных не перехватывается |
| Детекторная лента | Не начата | Проверить block_signal/is_signal_source + scheduled reset и соседние обновления |
| Перенаправляющая лента | Не начата | Redstone/соседи и выбор направления без сохранения runtime entity ID |
| Сортирующая лента | Не начата | Фильтры, GUI, сохраняемый инвентарь настроек |
| Выбрасывающая лента | Не начата | Извлечение first/last/random, stacks/items/all, redstone и GUI |
| Подъёмник вверх/вниз | Не начата | Вертикальный контакт, форма и переходы между лентами |
| Разветвитель | Не начата | Пространственная маршрутизация и фильтры |
| Липкие ботинки | Не начата | Нужны после переноса движения игроков |
| Legacy-переключатель рецептов | Не начата | Сейчас выбран medium-набор; повреждённый legacy-рецепт сортировщика не перенесён |

Ни одна следующая механика пока не объявлена «Заблокирована возможностями Horizon»: отсутствие её реализации не доказывает отсутствие API. Для текущих лент стабильный публичный setter клиентской скорости отсутствует; проверенный pin-specific адаптер 0.1.1 сохранён без расширения записи на позиции/стеки.

## Следующая последовательность

1. Игровая приёмка новых быстрой/тормозной лент и регрессия обычной ленты.
2. Транзакционная передача в vanilla-инвентарь и возврат непоместившегося остатка; затем детекторная лента.
3. Перенаправление, фильтры/GUI, выбрасывание; подъёмники, разветвитель и дополнительные правила общей ленты.
4. Только после Transport — общие компоненты Core и основной контент, затем Logic, Storage, Mobile и остальные исходные модули по зависимостям.
5. Планы/удалённые функции категории 3 ведутся отдельно; они не выдаются за готовый функционал PowerCraft 2 и не увеличивают текущий заявленный объём.
