# Текущее состояние: 0.3.0

Три конвейера версии 0.2.0 подтверждены пользователем, база сохранена тегом powercraft2-v0.2.0-tested. В 0.3.0 восстановлен следующий существующий компонент оригинала: normal/brake передают предметы в соседние vanilla-инвентари с учётом направления, граней, приоритета и остатка. Новых блоков/предметов/рецептов нет, все 29 старых content-файлов и клиентское движение сохранены.

Прошли 37 Rust- и 25 Python-тестов, форматирование/Clippy, официальный cargo check настоящего Horizon с модом, официальный content build и валидатор обоих архивов. **Передача 0.3.0 в игре ещё не проверена.** Сохранение/реальные слоты/компоненты/LAN/FPS требуют приёмки из TESTING.md. Полный мод не завершён.
