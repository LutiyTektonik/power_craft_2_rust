# Текущее состояние: 0.7.0

Добавлена `powercraft2:ejector_conveyor`: извлекает из соседних ванильных контейнеров по фронту сигнала редстоуна. В меню выбираются режим и порядок слотов, а также настройка количества. При удержании питания повторных операций нет. Рецепт восстановлен из опубликованной 0.1.0B.

Windows-прогон подтвердил пять маршрутов перенаправления при facing east, три выхода сортировщика, деление 11/5 из 16, меню на 18 ячеек и сохранение пяти образцов после перезапуска. Исправлена регистрация сортировщика: свойство facing наследуется от бочки.

Игровые сценарии 0.7.0 приведены в [TESTING.md](TESTING.md). Проверки и хеши пакетов находятся в [VERIFICATION.json](VERIFICATION.json). Ветка `work/transport-ejector` основана на `d408164`. Следующая механика в очереди — подъёмник.
