# Состояние прототипа: исправление 0.1.1

Пользователь подтвердил работоспособность исходного конвейера 0.1.0 в одиночном Horizon: блок размещается, предметы движутся по направлению. Обнаруженное движение рывками исследовано по исходникам фактической сборки `9f42064c11efe7ef3e5ed2baad7ddc2a3b36eea0` с Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`.

## Что изменено

Сервер поддерживал скорость ленты, клиент замедлял предмет трением между пакетами с интервалом 20 тиков. Коррекция позиции без интерполяции создавала скачки. В 0.1.1 добавлено применение той же механики после клиентской физики через именованный `tick`. Позиции не переписываются, скорость не увеличена. Гравитация, столкновения, подбор, слияние и сохранение остаются в Horizon. Подробности и ограничения внутреннего клиентского адаптера — [SMOOTH_MOVEMENT.md](SMOOTH_MOVEMENT.md).

Контент 0.1.0, namespace, рецепт, форма и `facing` не менялись. Другие большие модули PowerCraft не реализованы. Мигратора Forge-миров нет.

## Файлы и установка

- `dist/powercraft2-0.1.1.hnmod` — официально упакованный исходный bundle с минимальной обработкой дескриптора для строгого pin. Его должен собрать Launcher; готовой Windows DLL внутри нет.
- `dist/powercraft2-0.1.0-content.hmod` — прежний, побайтно неизменённый контент; официальный валидатор успешно его проверил.
- `dist/powercraft2-windows11-test-kit.zip` — эти файлы, распакованный native-вход, инструкция, текущий отчёт и журналы проверок.

Заменить только нативную часть и выполнить rebuild в Launcher. [WINDOWS11.md](WINDOWS11.md) содержит точную команду и игровые сценарии. Плавность после исправления, реальная нагрузка, подбор, сохранение мира и LAN требуют игровой приёмки.

Изменения ведутся в локальной ветке `fix/conveyor-continuous-motion`. Origin не задан, GitHub push не выполнялся. Сторонние ветки не изменялись. Ограничения исходной Cloud-сети преодолены разрешённым сетевым режимом; Rust, rsync и инструментарий установлены локально без изменения системных каталогов.
