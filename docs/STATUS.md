# Текущее состояние: 0.5.0

Следующий компонент Transport реализован как `powercraft2:redirector_conveyor`. Восстановлены выбор маршрута по редстоуну и соседям, разгрузка по направлению установки и рецепт опубликованной 0.1.0B. Применяются прежние физика предметов, пины Horizon/Mixins и семь типов поддержанных контейнеров.

Версия 0.4.0 прошла локальный игровой прогон на Windows в экземпляре `PowerCraft2-040-Test`. Три ленты разгрузили по 16 предметов в пустые сундуки. У Speedy частично заполненный сундук принял 5 из 16, а полный отказал без потери предметов. Детектор дал 15 при игроке и при предмете, затем вернул 0 после освобождения ленты. Повторный вход, LAN и остальные типы контейнеров этот прогон не охватывал.

Для 0.5.0 см. [VERIFICATION.json](VERIFICATION.json) и [TESTING.md](TESTING.md). Рабочая локальная ветка `work/transport-redirector` основана на `work/transport-detector` (`dd34b14`). Следующий компонент Transport после игровой проверки маршрутов — сортирующая лента с фильтрами.
