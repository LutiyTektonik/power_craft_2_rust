# Текущее состояние: 0.6.0

Добавлена `powercraft2:separator_conveyor`: меню с 18 сохраняемыми ячейками, сортировка выпавших предметов, деление стопок и выгрузка в контейнер на выбранном выходе. Перенаправляющая лента 0.5.0 входит в эту сборку.

Windows-прогон подтвердил пять маршрутов перенаправления при facing east, три выхода сортировщика, деление 11/5 из 16, меню на 18 ячеек и сохранение пяти образцов после перезапуска. Исправлена регистрация сортировщика: свойство facing наследуется от бочки.

Версия 0.4.0 прошла локальный игровой прогон на Windows в экземпляре `PowerCraft2-040-Test`. Три ленты разгрузили по 16 предметов в пустые сундуки. У Speedy частично заполненный сундук принял 5 из 16, а полный отказал без потери предметов. Детектор дал 15 при игроке и при предмете, затем вернул 0 после освобождения ленты. Повторный вход, LAN и остальные типы контейнеров этот прогон не охватывал.

Игровые сценарии для обеих новых лент находятся в [TESTING.md](TESTING.md), результаты сборки в [VERIFICATION.json](VERIFICATION.json). Работа сохранена в локальной ветке `work/transport-separator`, основанной на `work/transport-redirector` (`aa74ac9`). Следующая механика — выбрасывающая лента.
