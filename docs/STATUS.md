# Текущее состояние: 0.2.0

Продолжен существующий проект. Проверенная пользователем ordinary conveyor 0.1.1 отмечена тегом `powercraft2-v0.1.1-tested`; она не переписана с нуля. В 0.2.0 добавлены быстрая и тормозная ленты, их контент и рецепты. Сохранены исходный normal ID/данные и точные Horizon/Mixins SHA.

Реально прошли 25 Rust- и 22 Python-теста, форматирование/Clippy, официальный cargo check настоящего Horizon с модом, официальные content build и проверки обоих архивов. Новые ленты **реализованы, не протестированы в игре**. Проверка Windows/Minecraft 0.2.0, LAN, реальных FPS/TPS и всех краёв ещё требуется.

[Полный прогресс](PORTING_PROGRESS.md), [текущий отчёт](VERIFICATION.json), [инструкция Windows](WINDOWS11.md), [приёмка](TESTING.md), [история](../CHANGELOG.md).

Исходный реестр содержит 427 Java-классов, 62 декларации объектов (включая служебные), 177 объявлений рецептов разных режимов и 78 GUI/container/виджет-классов. Источник проверен по 445 Git blob ID. Категории оригинала отделяют исходные реализации, проблемные Logic/Storage/Mobile и планы/удалённое. Инвентаризация не объявляется запуском старого Forge.

Артефакты: `dist/powercraft2-0.2.0.hnmod`, `dist/powercraft2-0.2.0-content.hmod`, `dist/powercraft2-windows11-test-kit.zip`. Native — source bundle, Launcher должен его собрать. В отличие от hotfix 0.1.1, обновить нужно обе части.

Текущая работа — локальная ветка `work/transport-expansion`. Origin не настроен; push/PR не выполнены, чужие ветки не изменялись. Большие исходники, инструменты, кэш и артефакты не добавлены в Git. Следующий шаг после игровой приёмки — атомарная передача в инвентарь и детекторная лента; весь мод ещё не завершён.
