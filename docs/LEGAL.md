# Лицензии и происхождение

Проверено 14 ноября 2026 года. Это описание обнаруженных разрешений и выбранного состава проекта, не юридическое заключение.

## Оригинальный PowerCraft 2

[Страница CurseForge](https://www.curseforge.com/minecraft/mc-mods/powercraft-2), project ID 321376, указывает **MIT License**. Автор страницы — DannikInfo; описание называет исходный PowerCraft MightyPork, XOR и Rapus. Эта информация не доказывает права на каждый исторически унаследованный ресурс.

В полном дереве [PowerCraft/2.0 на выбранном commit](https://github.com/PowerCraft/2.0/tree/795369c5a03c7cf39307398a432a5d644698e1df) не обнаружено файлов с именами LICENSE, COPYING или NOTICE. Дерево не усечено; инвентаризация содержит 427 Java-файлов и в `resources/` 242 PNG и два LANG-файла. Отдельный текст условий для каждой текстуры, модели и звука не найден. В дереве ресурсов звуковые файлы не обнаружены; модели присутствуют как Java-классы. Это не аудит всей истории и сторонних выпусков.

| Материал | Решение |
| --- | --- |
| Java-код | Изучены модули, регистрация, NBT, исходный normal belt и BeltHelper; Java-код в новый проект не включён |
| Текстуры и значки | Не включены; индивидуальное происхождение не подтверждено |
| Java-модели и графические материалы | Не включены |
| Звуки и материалы из внешних релизов/старого Maven | Получены в составе официальных архивов только для статического аудита; не включены |
| Названия проекта и механик | Используются описательно; разрешение на товарные знаки и официальный статус не подразумевается |

Rust-реализация написана заново по изученному поведению, без механического перевода Java-файлов. Точные пути исходных классов перечислены в `POWERCRAFT_INVENTORY.json`; этот файл содержит имена, а не оригинальный код.

## Новый проект

Новый код и собственные временные текстуры распространяются по MIT из корневого `LICENSE`. Семь текстур 16×16 созданы детерминированным `scripts/textures.py`, без скачанной графики; проверяется их точное соответствие генератору. Они намеренно простые. Никаких Minecraft jar, vanilla-текстур, моделей, звуков, подготовленных ресурсов или исполняемых файлов игры в Git нет. Ссылки на `minecraft:iron_block` и идентификаторы рецепта — ссылки на ресурсы пользователя, не копии материалов.

Официальные `native/tools/native.py` и `native/tools/game.py` происходят из Horizon Mods указанной в lock-файле ревизии. В корне этого репозитория LICENSE не найден; GitHub metadata возвращает `license=null`. Лицензия `native/coords-hud/LICENSE` относится к отдельному моду, её нельзя автоматически распространить на соседние общие инструменты. Поэтому копии этих двух скриптов используются только как локальные внешние инструменты, исключены из Git и исходного архива; `scripts/fetch-tools.py --download` получает их по SHA и проверяет Git blob ID. Они не входят и в игровые `.hmod`/`.hnmod`. Корневая MIT-лицензия нового проекта не приписывается этим внешним файлам.

Исходники engine/Mixins также не включены в репозиторий; при сборке они скачиваются по своим MIT-лицензиям.

Перед заимствованием оригинальной графики или кода сверх изучения поведения необходимо проверить конкретный файл, полный текст лицензии и право автора на исторический материал. Публичность репозитория не считается самостоятельным разрешением.

При развитии 0.2.0 по Git blob ID проверены все 445 исходных/build-файлов оригинала. В Git включён только фактический индекс имён/рецептов/ссылок, не Java-тексты или оригинальные ресурсы. Новые изображения быстрой и тормозной лент также созданы нашим генератором.

При уточнении 0.3.0 скачаны 26 официальных Maven runtime/source-JAR 0.1.0B по закреплённым Git blob ID, проверены CRC/состав/class headers, код не запускался. В проекте распространяются только hashes/имена/данные рецептов/ссылки анализа. Java-тексты и ресурсы из архивов не включены. Публикационная MIT-метка CurseForge не снимает прежнюю неопределённость происхождения отдельных унаследованных ресурсов; разрешённой новой графики из них не заимствовано.

Для detector 0.4.0 два изображения созданы нашим генератором, модель получена из собственной модели ленты. Звук — ссылка minecraft:block.lever.click на штатные ресурсы пользователя; аудиофайл не распространяется.
