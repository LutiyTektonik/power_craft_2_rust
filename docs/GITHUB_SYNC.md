# Синхронизация с GitHub

Репозиторий: https://github.com/LutiyTektonik/power_craft_2_rust . Рабочая ветка: `work/transport-detector`.

2026-11-14 доступ исправлен: реальный `git push -u origin work/transport-detector` прошёл успешно. `git ls-remote` подтвердил опубликованный коммит 6e6834abb91626047f1ef7100d059ba287345e94 с полной родительской историей. Ранее записанные HTTP 403 относятся к предыдущим попыткам до исправления подключения.

Последующие изменения подготовки локального окружения сохраняются в этой же собственной ветке. Не заменять чужие ветки, не применять `--mirror`/`--force` и не перезаписывать существующие теги. Отправка проверенных баз и ветки выполняется так:

```sh
git push -u origin work/transport-detector
git push origin refs/tags/powercraft2-v0.2.0-tested refs/tags/powercraft2-v0.1.1-tested
git ls-remote --heads --tags origin
```

Инструкция переноса — [LOCAL_DEVELOPMENT.md](LOCAL_DEVELOPMENT.md). Исходники/документация/конфигурация находятся в Git; установочные пакеты, ZIP переноса и кэши не добавляются в Git. Полная локальная история всех веток и тегов также включается в `project.bundle` переносного ZIP. Авторизация аккаунтов и секреты не переносятся.
