# Синхронизация с GitHub

Пользователь указал целевой репозиторий: https://github.com/LutiyTektonik/power_craft_2_rust.git . Локальный origin настроен на него; рабочая ветка — work/transport-detector. Игровая версия остаётся 0.4.0, исходный feature-коммит — c7a850b.

На момент проверки GitHub-коннектор подключён как LutiyTektonik-dev, владелец репозитория — LutiyTektonik. API вернул pull=true, push=false. Отправка не выполнена, удалённые ветки не изменялись. Отдельная CLI-авторизация этой среды также не прошла проверку; секреты не выводились и не менялись.

Для синхронизации требуется право записи: подключить аккаунт владельца либо предоставить LutiyTektonik-dev доступ Write к этому репозиторию, а используемому приложению GitHub — доступ к нему. Приглашение сотрудника нужно принять. Токены не передавать в чат; авторизацию настраивать штатным подключением GitHub/Codex.

После исправления доступа повторно проверить identity/permissions и существующие refs, затем отправить только свою ветку и теги без force push:

```sh
git push -u origin work/transport-detector
git push origin refs/tags/powercraft2-v0.2.0-tested refs/tags/powercraft2-v0.1.1-tested
```

Не заменять main, не применять --mirror/--force и не перезаписывать существующие теги. Если история удалённого репозитория уже существует, сначала исследовать её; подготовить отдельную ветку/PR с сохранением чужих изменений. Для пустого репозитория PR может быть недоступен до появления базовой ветки.

Артефакты/кэши/исходники движка не добавлять в Git. Полная локальная история и теги также сохранены в ранее подготовленном source-and-history ZIP. Этот документ фиксирует подготовку, не успешный push.
