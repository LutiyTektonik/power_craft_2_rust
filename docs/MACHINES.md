# Машины PowerCraft 2 Horizon

## Банк опыта

Ветка `work/machines-first` добавляет `powercraft2:xp_bank`. Блок копит XP из сфер и позволяет внести или забрать всё либо сумму до ближайшей границы уровня. Транзакцию рассчитывает сервер по фактическому уровню и прогрессу игрока. Уровни, уже потраченные, например, на зачарование, нельзя внести через устаревшее накопительное поле общего XP.

| Действие | Результат |
| --- | --- |
| Внести один уровень | Если полоса заполнена частично, вносится её текущий прогресс. Иначе вносится стоимость последнего завершённого уровня. |
| Забрать один уровень | Банк переводит ровно столько XP, сколько нужно до следующего уровня, либо отдаёт остаток. |
| Внести или забрать всё | Перевод ограничен доступным XP и вместимостью получателя. |
| Подвести сферы опыта | Банк принимает сферы, пересекающие куб блока с запасом 0,5 блока, по 32 сущности за тик. Частично принятая объединённая сфера сохраняет оставшееся количество. |
| Добыть банк в выживании | Опыт из банка переводится добывшему игроку. Если часть опыта не удалось выдать, она сохраняется в NBT выпавшего блока и восстанавливается после установки. |

Банк использует штатную сериализацию сущности блока и два поля меню по 16 бит, чтобы показать баланс вплоть до 2 147 483 647. Число XP берётся только с сервера. Если другой мод отменяет перевод или меняет его сумму, банк пропускает операцию. Перевод выдаёт опыт напрямую, как в оригинале, поэтому он не чинит предметы с Починкой.

Прямой перевод на добыче выполняется в обычном выживании, когда включены дропы и блок выпал. Если у блока нет дропа, например при удалении командой или в творческом режиме, баланс при этом не переносится. Габариты модели и коллизии соответствуют пустому банку оригинала. Изменение геометрии при наполнении и игровой прогон остаются отдельными задачами.

Рецепт опубликованной версии `0.1.0B` создаёт один банк. Ряды `ODO`, `OGO`, `O O`, где O — обсидиан, D — алмазный блок, G — слеза гаста. Источник — `machines-0.1.0B-src.jar`, Git blob `efff9412849eb7caa980f83c748d8b451661b14b`, классы `PCma_App`, `PCma_BlockXPBank`, `PCma_TileEntityXPBank`, `PCma_GuiXPBank`. Русские и английские подписи добавляются в общую локализацию при интеграции. Модель построена из кубоидов со ссылками на текстуры Minecraft. [Реестр опубликованных файлов](PUBLISHED_FILES.json)

### Проверка после обновления

1. Собрать рецепт и открыть меню. После `/xp add @s 20 points` на пустой полосе получить уровень 2 и 4 XP прогресса. Внесение одного уровня даёт банку 4 XP и оставляет игроку уровень 2 без прогресса. Внесение всего переводит в банк ещё 16 XP.
2. Забрать один уровень. На уровне 0 получите 7 XP, запас уменьшится до 13. Забрать всё и проверить возврат к уровню 2 с 4 XP прогресса.
3. Бросить пузырёк опыта у банка, отойти от него, открыть меню и проверить поступление. Сохранить мир, загрузить его вновь и подтвердить баланс.
4. Внести XP, выйти из меню, добыть блок в выживании с включёнными дропами и проверить изменение опыта игрока. Проверить одинаковый результат при добыче с Шёлковым касанием.
5. В мире с двумя игроками открыть один банк одновременно и нажать «Забрать всё» у обоих. Опыт должен получить только тот, чья операция обработана первой, остаток должен исчезнуть у обоих клиентов.

Применяются шесть тестов Rust для арифметики, диапазонов, объединённых сфер и передачи баланса, два теста Python форматов контента и штатная сборка .hmod. На версии движка `9f42064c11efe7ef3e5ed2baad7ddc2a3b36eea0` меню использует именованные хуки `block_entity`, `block_entity_ticks`, `block_entity_tick`, `block_entity_container`, `screen`, `screen_click`, `screen_draw` и `menu_button`. Путь при добыче использует `loot_function` и `loot_drops`.
