# Core

Первый срез Core использует реестры контентного мода из закреплённого Horizon. Оригинал сверялся с опубликованными исходниками Core и API 0.1.0B. Git blob исходников Core — `593021b6e12b36208c7d66d989eefc7022003642`. Архив прошёл проверку CRC. [Исходники релиза PowerCraft](https://github.com/PowerCraft/Maven/tree/2fce13e3dccd0ec0a9db7dd19416d308509bfa1c/1.7.10/powercraft)

| Механика | Реализация | Проверка |
| --- | --- | --- |
| Кристалл силы | Восемь вариантов с отдельными ID, собственная модель группы кристаллов на штатных текстурах стекла, выпадение своего цвета и генерация среди камня | Проверены связи реестров, граф генерации и структура пакета. Игровая проверка предстоит |
| Пыль силы | Один кристалл любого цвета даёт четыре единицы пыли. Пыль блестит и даёт 3600 тиков горения в печи | Проверены рецепт и компонент топлива. Игровая проверка предстоит |
| Ядра крафта, формирования, аннигиляции и датчика | Четыре независимых рецепта. Ядро крафта требует красный кристалл, ядро датчика — бирюзовый. Ядра складываются по одному | Проверены ингредиенты, результаты и пределы стопок. Игровая проверка предстоит |

Оригинальный Java-генератор выбирает вариант цвета один раз для чанка, затем делает 12 попыток с размером жилы 4. Диапазон центров жил — Y от 5 до 14 включительно. В Horizon внешний генератор один раз на чанк равновероятно выбирает один из восьми вложенных генераторов цвета. Биомный модификатор добавляет её в подземные руды обычного мира. Объект заменяет `minecraft:stone`. Расположение отдельных блоков зависит от алгоритма жил и генератора Horizon. Соседний чанк может внести жилу своего цвета.

Отдельные ID представляют прежние метаданные 0–7 в порядке `orange`, `red`, `green`, `blue`, `white`, `magenta`, `cyan`, `yellow`. Для смены набора модов с генерацией перезапустите игру. Проверять добычу следует в новом мире или в ранее не сгенерированных чанках.

Light, Hologram и Teleport могут ссылаться на эти ID кристаллов из собственных рецептов. В Horizon идентификатор цвета однозначно заменяет метаданные рецепта 1.7.10. Реакция кристалла на луч зависит от переноса Light. Атмосферные частицы и звуки остаются частью порта кристалла.

| Оставшаяся механика оригинала | Что требуется и почему |
| --- | --- |
| Переносной верстак | Не начат. У оригинала два экрана. Обычное применение открывает меню подбора рецепта и работы с инвентарём, применение в приседе — обычный верстак 3×3. Рецепт использует ядро крафта |
| Активатор | Не начат. Исходное действие перебирает обработчики модулей, ищет 3D-рецепт и умеет извлекать блок-сущность. Требуются серверная проверка прав и безопасные операции с миром. Рецепт допускает любой кристалл |
| Рудоискатель | Не начат. Оригинал вызывает экран при применении на блоке и расходует единицу прочности из 500. Требуются проверка регистрации экрана и серверная реализация поиска. Рецепт допускает любой кристалл |
| Сохранение блока | Не начато. Собственный класс опубликованного блока задаёт рендер и скрывает предмет из обычного списка. Поведение зависит от вызывающего его активатора и правил переноса данных блок-сущности |
| Настройка спавнера | Не начата. Оригинальный пакет меняет сущность спавнера по переданным координатам. Нужна проверка полномочий и типа цели через Horizon |
| Переработка и рецепт спавнера | Не начаты. Рецепты включаются отдельными настройками оригинала. Для переработки требуется сверить выход с современными рецептами, чтобы сохранить баланс материалов |

## Проверка в Horizon

1. В творческом мире откройте вкладку Core и проверьте восемь цветов кристалла и пять ресурсов. Поставьте и добудьте кристалл каждого цвета. Сверьте цвет выпавшего блока.
2. Изготовьте пыль из каждого цвета. Проверьте выход в четыре единицы и горение 3600 тиков в обычной печи.
3. Изготовьте четыре ядра по схемам ниже. Поменяйте местами красный и бирюзовый кристаллы в двух рецептах и убедитесь, что такой ингредиент отклоняется.
4. В новом обычном мире осмотрите несколько чанков у Y=5–14. Проверьте, что жилы генерируются в камне. Для проверки отдельной жилы можно вызвать `/place feature powercraft2:power_crystal_orange_vein` в окружении камня.
