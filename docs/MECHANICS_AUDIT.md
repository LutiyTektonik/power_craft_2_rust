# Аудит механик PowerCraft 2 на 0.10.0

Объём сверён с опубликованной 0.1.0B и с текущим деревом порта. В таблицах присутствуют 62 декларации из реестра, включая рецептурные компоненты и служебные обработчики. Mobile указан отдельно. «Подтверждена пользователем» относится к проверенному сценарию прежнего выпуска. Результаты проверки 0.10.0 приведены в [VERIFICATION.json](VERIFICATION.json).

Источники: [опубликованная версия](PUBLISHED_RELEASE.md), [реестр](ORIGINAL_REGISTRY.md), [индекс классов и рецептов](PUBLISHED_MECHANICS.json), [план по зависимостям](PORTING_PLAN.md).
