# PowerCraft 2 Horizon

Transport-прототип PowerCraft 2 на Rust. Пользователь подтвердил установку конвейера и движение предметов в одиночной игре на Horizon `9f42064c11efe7ef3e5ed2baad7ddc2a3b36eea0`. Нативная версия **0.1.1** устраняет причину рывков: клиент теперь предсказывает ту же силу ленты после штатной физики, что и сервер. Проверить плавность нового выпуска в игре ещё требуется.

Скорость не повышалась. Позиции и рендер не подменяются. Столкновения, гравитация, слияние, сохранение, despawn и подбор остаются у Horizon. Контент **0.1.0** сохраняется без изменений: `powercraft2:conveyor`, четыре направления, рецепт и форма высотой ¼ блока. Только нативную часть следует заменить и пересобрать Launcher.

Подробности: [причина и исправление](docs/SMOOTH_MOVEMENT.md), [текущие проверки](docs/SMOOTH_MOVEMENT_VERIFICATION.json), [совместимость](docs/COMPATIBILITY.md). Старый `WINDOWS11_VERIFICATION.json` — исторический отчёт первоначальной ревизии, а не статус hotfix.

## Проверки и сборка

```sh
scripts/bootstrap.sh --install
scripts/check.sh                  # Python, rustfmt, Clippy, Rust unit tests
scripts/build.sh --source-only    # исходный native bundle + строгий pin; без сборки игры
scripts/check.sh --horizon        # официальная компиляционная и форматная проверка
python3 scripts/prepare-windows.py
```

Реально выполнены **17 Rust-тестов** и **15 Python-тестов**. Регрессия воспроизводит старое рассогласование за 20 тиков. Модель проверяет равные траектории при группировке тиков под 5–144 FPS и партиях до 4096 предметов; это не замер FPS или TPS настоящего мира. Результат официального cargo check с модом и форматного валидатора фиксируется отдельно от запуска игры.

Пины — в `upstream.lock.json`. Mixins остаётся `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`. Новая цель — фактически запущенная пользователем версия; исходный prototype pin f4d8d62 не заменяет её.

## Установка hotfix

Оставьте `powercraft2-0.1.0-content.hmod`. Замените старую native-часть файлом `powercraft2-0.1.1.hnmod` и выполните native rebuild в Horizon Launcher. В распакованном наборе можно передать `native-pinned/` целиком команде Launcher из [инструкции](docs/WINDOWS11.md). Нативное исправление нужно также на клиенте сервера/LAN.

`dist/powercraft2-0.1.1.hnmod` создаётся официальным `native.py package`, затем из дескриптора удаляется только необязательный `hooks`, чтобы Launcher не сменил commit, связанный с внутренним клиентским адаптером. Rust-payload не меняется; результат проверяется официальным валидатором при доступных инструментах. Не держать два native-архива одного ID. SHA-256 — в отчёте/наборе.

## Структура

| Путь | Назначение |
| --- | --- |
| `native/powercraft2/mixins/powercraft2/transport.rs` | Общее независимое ядро и Rust-тесты |
| `item_tick.rs` | Авторитетный серверный Post |
| `client_tick.rs` | Клиентское предсказание на игровом тике |
| `placement.rs`, `listen.rs` | Размещение и подключение серверного события |
| `content/` | Неизменённые данные блока, предмета и рецепта |
| `scripts/`, `tests/`, `docs/` | Воспроизводимость, проверки и документация |

Готовых Logic, Storage, Mobile, энергетики и миграции Forge-миров нет. Проект не связан официально с Mojang, Microsoft или авторами PowerCraft. Исходники в Git не содержат Minecraft-ресурсы, cache и полное дерево Horizon.
