# PowerCraft 2 Horizon

Начат перенос PowerCraft 2 на Rust и Horizon. Созданы исходный прототип конвейера, контент и воспроизводимая упаковка. **Компиляция Rust и запуск в игре пока не подтверждены:** в этой Cloud-среде отсутствует Rust, а сетевой прокси недоступен для shell-команд. Это не готовый игровой релиз.

Цель: Minecraft 26.3, Horizon `f4d8d62c31ec2b08046faded7bef1b476783f319`. Идентификатор мода и пространство имён: `powercraft2`. Все ревизии записаны в [upstream.lock.json](upstream.lock.json).

Написаны: блок `powercraft2:conveyor` высотой ¼ блока, четыре направления, размещение по взгляду игрока, рецепт, собственные текстуры и Rust-обработчик скорости лежащих предметов. Направление хранится в состоянии блока. Движение вызывается серверным событием тика, без привязки к FPS. Указанное поведение необходимо подтвердить в игре; сейчас проверены структура, происхождение API и упаковка.

## Команды

Все инструменты и сборки могут находиться в Cloud; установка на компьютер пользователя для продолжения разработки не требуется.

```sh
scripts/bootstrap.sh                 # проверить инструменты
scripts/bootstrap.sh --install       # установить недостающий Rust/официальный CLI, если сеть разрешена
python3 scripts/fetch-tools.py --download # после чистого checkout: получить внешние native-инструменты
scripts/check.sh --static            # доступные Python-проверки
scripts/check.sh                     # дополнительно fmt, Clippy и Rust-тесты
scripts/build.sh --source-only       # упаковка исходников/контента, без компиляции
scripts/check.sh --horizon           # настоящая проверка интеграции и архивов, требует сети и Rust
scripts/build.sh --horizon           # дополнительно собрать модифицированный клиент
```

В текущей среде прошли 13 Python-тестов. Написаны 11 Rust-тестов, но они не запускались. Полный список результатов — [docs/STATUS.md](docs/STATUS.md).

Для Windows 11 подготовлены [инструкция Launcher](docs/WINDOWS11.md), [аудит функций](docs/FEATURE_AUDIT.md) и [отчёт команд](docs/WINDOWS11_VERIFICATION.json). `python3 scripts/prepare-windows.py` собирает экспериментальный набор после упаковки исходников; он явно помечен как не прошедший компиляцию и игровые тесты. Содержит вход Launcher со строгими Horizon/Mixins pins и контрольными суммами.

`dist/powercraft2-0.1.0-content.hmod` содержит блок, рецепт и ресурсы. `dist/powercraft2-0.1.0.hnmod` содержит нативные исходники; он создан официальным `native/tools/native.py package powercraft2`. Наличие этих файлов не означает, что Rust собран или что архивы прошли официальный `cargo horizon-mod check`.

## Структура

| Путь | Назначение |
| --- | --- |
| `native/powercraft2/mixins/powercraft2/transport.rs` | Независимая механика, та же исходная единица для Cargo и Horizon |
| `native/powercraft2/mixins/powercraft2/*.rs` | Тонкие адаптеры настоящих API Horizon |
| `content/` | Контент API 0.2; отдельная часть `.hmod` |
| `native/tools/` | Место локальных внешних инструментов; копии не включены в Git |
| `scripts/` | Установка, аудит, проверки, упаковка |
| `tests/` | Проверки схем, отрицательных случаев и воспроизводимости архивов |
| `docs/` | Архитектура, перенос, лицензии, совместимость и статус |

## Проверка в игре после компиляции

Нужны подготовленные ресурсы собственной копии Minecraft 26.3. Они не входят в проект. Официальный `native.py build powercraft2` выводит путь к клиенту; запускать его следует из отдельного тестового каталога, передав `--resources /абсолютный/путь/к/ресурсам`.

Контентный `.hmod` помещается в `horizon-mods/` этого тестового каталога и включается в Options → Mods до входа в мир. `.hnmod` должен быть собран совместимым лаунчером либо через указанный официальный скрипт; помещение его в папку контентных модов не компилирует код.

Получение: вкладка «PowerCraft 2: Транспорт», рецепт из трёх кож, двух слитков железа и красной пыли, либо `/give @s powercraft2:conveyor 64`. Для явной ориентации: `/setblock ~ ~ ~ powercraft2:conveyor[facing=east]`. Проверить линию, поворот, границу чанка, сохранение/загрузку и двух игроков по [docs/STATUS.md](docs/STATUS.md).

Существующий мир Java 1.7.10 автоматически не переносится. Другие функциональные области пока только спланированы. Проект не связан официально с Mojang, Microsoft или авторами PowerCraft.
