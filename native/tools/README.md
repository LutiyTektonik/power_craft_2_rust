# Официальные инструменты

`native.py` и `game.py` загружаются с точного commit Horizon Mods и проверяются по Git blob ID из `docs/TOOL_PROVENANCE.json`. Их копии в этом каталоге — локальные внешние инструменты, исключённые из Git и архива исходников нашего проекта.

```sh
python3 scripts/fetch-tools.py --download  # получить недостающие
python3 scripts/fetch-tools.py             # проверить уже имеющиеся без сети
```

Корневая лицензия Horizon Mods не обнаружена. Поэтому этим скриптам не приписана лицензия соседнего мода, и они не перераспространяются нашим репозиторием. При разработке в текущей Cloud-среде проверенные копии уже доступны. Скрипты используются без изменения.
